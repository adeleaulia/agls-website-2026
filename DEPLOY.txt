PANDUAN DEPLOY AGLS KE CLOUDFLARE WORKERS

Folder proyek: C:\Users\ARTOTEL GROUP\Documents\ChatGPT\Princess\agls-workers
File situs yang diedit: public/index.html dan aset di public/.
Salinan asli di Downloads tidak diubah.

1. Buka PowerShell dan masuk ke proyek:
   cd "C:\Users\ARTOTEL GROUP\Documents\ChatGPT\Princess\agls-workers"

2. Jika pindah komputer atau dependency belum terpasang:
   npm.cmd ci
   Gunakan Node.js LTS yang didukung Wrangler.

3. Preview dengan runtime Cloudflare:
   npm.cmd run db:local
   npm.cmd run dev
   Buka http://127.0.0.1:8788/
   Ctrl+C menghentikan server. Port 8787 adalah preview lama dari Downloads.

4. Periksa kode dan paket tanpa menerbitkan:
   npm.cmd run check

5. Login akun Cloudflare:
   npx.cmd wrangler login
   Selesaikan login dan otorisasi di browser.
   npx.cmd wrangler whoami
   Jika memiliki beberapa akun, tambahkan account_id akun tujuan ke wrangler.jsonc.

6. Periksa name di wrangler.jsonc (default: agls-teaser).
   Nama yang sama dalam akun yang sama akan memperbarui Worker tersebut.
   Untuk proyek terpisah, pilih nama Worker yang belum digunakan.

7. Selesaikan konfigurasi D1 dan migrasi sesuai DATABASE.txt terlebih dahulu.
   Deploy hanya setelah persetujuan eksplisit. Terbitkan:
   npm.cmd run deploy
   Wrangler mencetak URL https://agls-teaser.<subdomain-akun>.workers.dev
   Buka URL yang benar-benar dicetak, bukan contoh di atas.

8. Setelah deploy, uji desktop dan ponsel, khususnya Safari:
   - Halaman, navigasi, gambar, playback dan seek video.
   - Form word wall dan tombol kontak.
   - Refresh serta akses URL aset langsung.

9. Domain sendiri (opsional):
   Dashboard Cloudflare > Workers & Pages > agls-teaser > Settings
   > Domains & Routes > Add > Custom Domain.
   Gunakan domain dalam zone Cloudflare akun tersebut dan ikuti petunjuk DNS.

UPDATE BERIKUTNYA
Edit public/, jalankan npm.cmd run check, kemudian npm.cmd run deploy.
Tidak ada proses build frontend. Wrangler mengemas Worker dan mengunggah public/.
Untuk integrasi Git: root directory adalah folder proyek ini, deploy command
npm run deploy, tanpa build frontend. Sertakan package-lock.json; jangan
unggah node_modules, .npm-cache, .wrangler, atau token ke repository.
